# Fondly

Personal finance tracker for Android — local-first, no accounts, no cloud sync.

## About

Fondly helps you track income, expenses, budgets, and savings entirely on your device.
No login, no backend, no external services — your financial data stays yours.

## Status

🚧 Early development — MVP in progress.

- Kotlin
- Jetpack Compose
- (Architecture, database, and other decisions to be documented as the project progresses)
